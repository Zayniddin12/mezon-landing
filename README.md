# `Mezon Landing Project`

### Technology:

- Nuxt 3
- TypeScript
- Tailwind CSS
- Node `v18` or higher but LTS `v20.11` recommended

### MODE: SSR

## Production build

```bash
yarn
yarn install
yarn build
```

## Development Server

Start the development server on localhost:8000 and localhost3000

```bash
yarn dev
```
